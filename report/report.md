## 1. Введение и постановка задачи

- **Цель проекта:** определить тип выращиваемой сельскохозяйственной культуры по мультиспектральному спутниковому временному ряду поля.
- **Формулировка задачи:** многоклассовая классификация.
- **Практическая ценность:** автоматическая классификация культур помогает мониторить посевы, оценивать структуру сельского хозяйства и проверять соответствие заявленных культур фактическому состоянию полей.
- **Основная метрика:** macro F1. Она выбрана из-за сильного дисбаланса классов: accuracy завышает качество модели, которая хорошо предсказывает только частые культуры.
- **Дополнительные метрики:** accuracy и balanced accuracy. Accuracy оставлена как интуитивная справочная метрика, balanced accuracy показывает средний recall по классам.

---

## 2. Поиск и описание данных

- **Источник данных:** EuroCropsML на Zenodo, https://zenodo.org/records/15095445. Датасет выбран, потому что он напрямую соответствует задаче классификации культур по Sentinel-2 временным рядам и уже содержит данные по трём странам: Latvia, Portugal, Estonia.
- **Описание датасета:**
  - Актуальная версия v11 опубликована 31 марта 2025.
  - Доступные архивы: `split.zip` — 20.7 MB, `preprocess.zip` — 1.47 GB, `raw_data.zip` — 3.28 GB.
  - Для CP1 используется только Portugal из `raw_data.zip`, потому что это уменьшает объём вычислений и позволяет самостоятельно сделать train/validation/test split.
  - `Portugal.parquet` содержит временные ряды Sentinel-2 признаков по полям и целевую переменную `EC_hcat_c`; `Portugal_labels.parquet` содержит соответствие `parcel_id` и класса.
  - Объём Portugal subset: 100 000 строк, 225 столбцов, 219 дат, 79 классов культур.

## 3. Обработка и подготовка данных

- **Полная очистка:**
  - Пропуски: date-columns содержат `None`, средняя доля пропусков по датам около 55.2%; для baseline отсутствующее наблюдение заменяется нулевым 13-мерным вектором.
  - Дубликаты: проверяются `parcel_id`, metadata rows и согласованность labels.
  - Выбросы: проверяются распределения и квантили 13 спектральных каналов на выборке наблюдений.
  - Типы данных: target приводится к строке, временные списки раскрываются в `float32` признаки.
- **Работа с фичами:**
  - Исходные временные признаки: 219 дат, в каждой дате 13 Sentinel-2 значений.
  - Для baseline без feature engineering признаки только разворачиваются в матрицу `date x band`, всего 2847 признаков. NDVI и другие доменные признаки пока не создаются.
- **Визуализации:** построены графики пропусков по датам, количества валидных наблюдений по полям, распределения классов, дисбаланса классов, распределения по NUTS-регионам, распределения значений по 13 каналам и средних временных профилей top-классов.
- **Сплит данных:**
  - Стратегия разбиения: собственный train/validation/test split 60/20/20 с fixed seed.
  - Чтобы избежать data leakage, разбиение выполняется по полям, а не по отдельным временным наблюдениям одного поля.

---

## 4. Baseline-модель

- **Модель:** `SGDClassifier(loss="log_loss")` со `StandardScaler`, без feature engineering. Это линейная логистическая baseline-модель, обучаемая стохастическим градиентным спуском.
- **Результаты:** метрики на val/test
  - Наивный `most_frequent` dummy на test: accuracy 0.296, balanced accuracy 0.016, macro F1 0.007.
  - Validation: accuracy 0.291, balanced accuracy 0.246, macro F1 0.136.
  - Test: accuracy 0.288, balanced accuracy 0.220, macro F1 0.126.
  - По accuracy обучаемый baseline близок к dummy из-за сильного дисбаланса, но по macro F1 и balanced accuracy он существенно лучше, поэтому macro F1 остаётся основной метрикой.
- **Цель:** точка отсчёта для сравнения с более сложными моделями

## 5. Заключение и дальнейшие шаги

- **Итоги CP1:** данные Portugal загружены и разобраны из общего `raw_data.zip`; выполнен EDA; подготовлена матрица признаков `date x band`; построены наивный dummy и обучаемый baseline.
- **Сравнение с dummy:** dummy получает accuracy около 0.296 за счёт самого частого класса, но macro F1 около 0.007. Обучаемый baseline имеет близкую accuracy, но значительно выше macro F1 и balanced accuracy.
- **Ограничения:** baseline использует простую замену пропусков нулями и не создаёт доменных признаков; редкие классы остаются сложными для модели.
- **Дальнейшие улучшения:** попробовать RandomForest, Gradient Boosting / LightGBM, PCA/SVD для уменьшения размерности, агрегации временных рядов, NDVI и другие спектральные индексы.
