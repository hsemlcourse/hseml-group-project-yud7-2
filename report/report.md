## 1. Введение и постановка задачи

- **Цель проекта:** определить тип выращиваемой сельскохозяйственной культуры по мультиспектральному спутниковому временному ряду поля.
- **Формулировка задачи:** многоклассовая классификация.
- **Практическая ценность:** автоматическая классификация культур помогает мониторить посевы, оценивать структуру сельского хозяйства и проверять соответствие заявленных культур фактическому состоянию полей.
- **Основная метрика:** macro F1. Она выбрана из-за сильного дисбаланса классов: accuracy завышает качество модели, которая хорошо предсказывает только частые культуры.
- **Дополнительные метрики:** accuracy и balanced accuracy. Accuracy оставлена как интуитивная справочная метрика, balanced accuracy показывает средний recall по классам.

## 2. Поиск и описание данных

- **Источник данных:** EuroCropsML на Zenodo, https://zenodo.org/records/15095445. Датасет выбран, потому что он напрямую соответствует задаче классификации культур по Sentinel-2 временным рядам и уже содержит данные по трём странам: Latvia, Portugal, Estonia.
- **Описание датасета:**
  - Актуальная версия v11 опубликована 31 марта 2025.
  - Доступные архивы: `split.zip` — 20.7 MB, `preprocess.zip` — 1.47 GB, `raw_data.zip` — 3.28 GB.
  - В работе используется Portugal subset из `raw_data.zip`, потому что это уменьшает объём вычислений и позволяет самостоятельно сделать train/validation/test split.
  - `Portugal.parquet` содержит временные ряды Sentinel-2 признаков по полям и целевую переменную `EC_hcat_c`; `Portugal_labels.parquet` содержит соответствие `parcel_id` и класса.
  - Объём Portugal subset: 100 000 строк, 225 столбцов, 219 дат, 79 классов культур.
  - После фильтрации классов с числом объектов меньше 3 для CP2 остаётся 99 983 поля, 66 классов и 288 engineered-признаков.

## 3. Обработка и подготовка данных

- **Полная очистка:**
  - Пропуски: date-columns содержат `None`, средняя доля пропусков по датам около 55.2%; для baseline отсутствующее наблюдение заменяется нулевым 13-мерным вектором.
  - Дубликаты: проверяются `parcel_id`, metadata rows и согласованность labels.
  - Выбросы: проверяются распределения и квантили 13 спектральных каналов на выборке наблюдений.
  - Типы данных: target приводится к строке, временные списки раскрываются в `float32` признаки.
- **Работа с фичами:**
  - Исходные временные признаки: 219 дат, в каждой дате 13 Sentinel-2 значений.
  - Для baseline без feature engineering признаки только разворачиваются в матрицу `date x band`, всего 2847 признаков.
  - Для CP2 построены 288 engineered-признаков: статистики по каждому Sentinel-2 каналу, месячные агрегаты, `valid_observation_count`, `missing_rate`, `zero_share`, а также NDVI/NDWI/NBR статистики.
  - Значимость признаков проанализирована через ANOVA F-score на train split. Наиболее информативными оказались медианные и квартильные значения B03/B04/B08, июльские NIR-агрегаты, `valid_observation_count` и `missing_rate`.
- **Визуализации:** построены графики пропусков по датам, количества валидных наблюдений по полям, распределения классов, дисбаланса классов, распределения по NUTS-регионам, распределения значений по 13 каналам, средних временных профилей top-классов и значимости признаков.
- **Сплит данных:**
  - Стратегия разбиения: собственный train/validation/test split 60/20/20 с fixed seed.
  - Чтобы избежать data leakage, разбиение выполняется по полям, а не по отдельным временным наблюдениям одного поля.

## 4. Baseline-модель

- **Модель:** `SGDClassifier(loss="log_loss")` со `StandardScaler`, без feature engineering. Это линейная логистическая baseline-модель, обучаемая стохастическим градиентным спуском.
- **Результаты:** метрики на val/test
  - Наивный `most_frequent` dummy на test: accuracy 0.296, balanced accuracy 0.016, macro F1 0.007.
  - Validation: accuracy 0.291, balanced accuracy 0.246, macro F1 0.136.
  - Test: accuracy 0.288, balanced accuracy 0.220, macro F1 0.126.
  - По accuracy обучаемый baseline близок к dummy из-за сильного дисбаланса, но по macro F1 и balanced accuracy он существенно лучше, поэтому macro F1 остаётся основной метрикой.
- **Цель:** точка отсчёта для сравнения с более сложными моделями

## 5. CP2: эксперименты

Для CP2 был добавлен отдельный пайплайн feature engineering и единая таблица экспериментов. Все модели обучались на одинаковом train/validation/test split с `RANDOM_SEED = 42`.

| Модель | Feature set | Test macro F1 | Test accuracy | Комментарий |
|--------|-------------|---------------|---------------|-------------|
| Most frequent dummy | raw_engineered | 0.007 | 0.296 | Наивная нижняя планка |
| SGD logistic | raw_engineered | 0.109 | 0.442 | Линейная модель на engineered-признаках |
| Ridge alpha=1 | raw_engineered | 0.075 | 0.151 | Гиперпараметр alpha=1 |
| Ridge alpha=10 | raw_engineered | 0.073 | 0.146 | Гиперпараметр alpha=10 |
| RandomForest | raw_engineered | 0.154 | 0.542 | Ансамбль деревьев |
| ExtraTrees sqrt | raw_engineered | 0.171 | 0.534 | Ансамбль деревьев, `max_features=sqrt` |
| ExtraTrees 0.5 features | raw_engineered | 0.191 | 0.557 | Лучшая модель |
| HistGradientBoosting lr=0.05 | raw_engineered | 0.135 | 0.541 | Gradient boosting |
| HistGradientBoosting lr=0.10 | raw_engineered | 0.123 | 0.530 | Подбор learning rate |
| PCA50 + Ridge | pca_50 | 0.037 | 0.057 | Уменьшение размерности |
| Voting ensemble | raw_engineered | 0.146 | 0.531 | Hard-voting ансамбль |

- **Перебор гиперпараметров:** проверялись `alpha` для Ridge, `max_features` для ExtraTrees, `learning_rate` для HistGradientBoosting.
- **Уменьшение размерности:** проведён PCA-эксперимент на 50 компонентах и построены графики 2D PCA projection и cumulative explained variance. PCA существенно сжимает данные, но в этой постановке качество хуже, чем у деревьев на полных engineered-признаках.
- **Ансамбли:** проверены RandomForest, ExtraTrees и hard-voting ensemble.

## 6. Финальная модель и выводы

- **Итоги:** данные Portugal загружены и разобраны из общего `raw_data.zip`; выполнен EDA; подготовлены baseline-признаки и engineered-признаки; построены dummy, baseline, 4+ моделей, ансамбли, PCA-эксперимент и таблица экспериментов.
- **Сравнение с dummy:** dummy получает accuracy около 0.296 за счёт самого частого класса, но macro F1 около 0.007. Обучаемый baseline имеет близкую accuracy, но значительно выше macro F1 и balanced accuracy.
- **Финальная модель:** `ExtraTreesClassifier(n_estimators=80, max_features=0.5, min_samples_leaf=2, class_weight="balanced")`. Она выбрана по лучшему validation macro F1 и даёт test macro F1 0.191 при accuracy 0.557.
- **Почему не PCA-модель:** PCA50 + Ridge показала низкий macro F1; вероятно, важные нелинейные и сезонные различия классов теряются при сильном линейном сжатии.
- **Ограничения:** классов всё ещё много, распределение сильно несбалансировано, редкие культуры остаются сложными для модели.
- **Дальнейшие улучшения:** использовать иерархию `EC_hcat_c`, объединять сверхредкие классы, пробовать специализированные модели временных рядов и более аккуратную обработку облачности/пропусков.
